# RW Digitalisasi

Sistem Informasi Administrasi RW Digitalisasi untuk membantu pengelolaan data warga, layanan administrasi, kegiatan, keuangan, inventaris, dan informasi RW.

## Fitur

- Manajemen akun dan hak akses
- Data warga dan kartu keluarga
- Surat menyurat
- Pengumuman
- Kegiatan dan QR absensi
- Keuangan dan iuran
- Inventaris RW
- Dashboard administrasi
- Manajemen role dan scope pengguna

## Teknologi

- Laravel 13
- PHP
- MySQL
- Blade
- Tailwind CSS
- JavaScript
